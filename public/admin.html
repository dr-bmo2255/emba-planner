📱 Send syllabi straight from your iPhone

Once set up, any PDF in Canvas, Mail, or Files can go to the planner from the Share button. You do this once, in the iPhone's Shortcuts app:

  1. Open Shortcuts → tap + → name it Add to EMBA Planner.
  2. Tap the ⓘ (Details) button → turn on Show in Share Sheet → under "Receive", choose PDFs only.
  3. Add the action Get Contents of URL. Set the URL to:

    Tap Show More: Method POST; Headers: add Authorization = Bearer followed by your shortcut key (make one below), and x-filename = the Shortcut Input → Name variable; Request Body File = Shortcut Input.
  4. Add the action Open URLs. It uses the result of the previous step automatically.
  5. Done. To use it: in Canvas, open the syllabus → Share (or "Open in…") → Add to EMBA Planner. This page opens with the file loaded.

Shortcut keys

A shortcut key lets the Shortcut upload as you. It's shown once; paste it into the Shortcut, then it lives only on your phone. Delete it here if the phone is lost.

Files sent this way are stored privately for 7 days, then deleted automatically.

Open questions

Items still waiting on a decision: group or individual not set, no point value, no date, or a ⚠ verify flag. Open one to edit it for everyone; saving or closing brings you back here. Dismiss one that doesn't need a decision (it's hidden for all admins, and comes back if a different question about it appears).
