📱 Send syllabi straight from your iPhone

Once set up, any PDF in Canvas, Mail, or Files can go to the planner from the Share button. You do this once, in the iPhone's Shortcuts app:

  1. Open Shortcuts → tap + → name it Add to EMBA Planner.
  2. Tap the ⓘ (Details) button → turn on Show in Share Sheet → under "Receive", choose PDFs only.
  3. Add the action Get Contents of URL. Set the URL to:

    Tap Show More: Method POST; Headers: add x-admin-passcode = your passcode, and x-filename = the Shortcut Input → Name variable; Request Body File = Shortcut Input.
  4. Add the action Open URLs. It uses the result of the previous step automatically.
  5. Done. To use it: in Canvas, open the syllabus → Share (or "Open in…") → Add to EMBA Planner. This page opens with the file loaded.

Files sent this way are stored privately for 7 days, then deleted automatically. Your passcode lives only inside the shortcut on your phone.
